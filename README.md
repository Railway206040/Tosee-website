# حزب توسعه البرز

وب‌سایت فارسی و راست‌چین برای معرفی حزب توسعه البرز و نامزدهای شورای دانش‌آموزی.

## اجرا
فایل `index.html` را در مرورگر باز کنید؛ سایت به بک‌اند یا دیتابیس نیاز ندارد.

## انتشار با GitHub Pages
1. وارد بخش **Settings** مخزن شوید.
2. از منوی کناری **Pages** را باز کنید.
3. در قسمت **Build and deployment**، گزینه **Deploy from a branch** را انتخاب کنید.
4. شاخه `main` و پوشه `/(root)` را انتخاب و **Save** کنید.
5. پس از آماده شدن انتشار، نشانی سایت در همان صفحه نمایش داده می‌شود.

## شخصی‌سازی
- متن معرفی حزب و نامزدها در فایل `index.html` قرار دارد.
- لینک کانال بله در بخش کانال قابل تغییر است؛ آدرس فعلی فقط به صفحه اصلی بله می‌رود.
- کارت‌های نامزدها فعلاً نمونه هستند و باید با اطلاعات تأییدشده جایگزین شوند.
- سایت از فونت Vazirmatn از Google Fonts استفاده می‌کند؛ در صورت در دسترس نبودن اینترنت، فونت جایگزین سیستم نمایش داده می‌شود.
